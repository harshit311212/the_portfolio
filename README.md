# Harshit's Domain Portfolio

A visually striking personal portfolio showcasing Harshit Shrivastava's AI, Python, and web development expertise.

## Features
- **Dynamic Spark Animation** on the hero text with continuous cursor trail and color spectrum.
- **Neon Green / Electric color** theme with a black background and vibrant #7FFF00 navbar.
- **Interactive Tech Stack Graph** built with D3.js (force‑directed, draggable).
- **Particle network background** (Higgfield effect) that matches the accent color.
- **Projects Section** consolidating the Extraction suite and AI Attendance system with live GitHub links.
- **Responsive design** powered by vanilla CSS and modern CSS variables.

## Quick Start
```bash
# Clone the repo
git clone https://github.com/harshit311212/the_portfolio.git
cd the_portfolio
# Open in a browser (no build step required)
start index.html   # Windows
```

## Development
- Edit `index.html`, `styles.css`, and `script.js` to tweak content or animations.
- The site uses only HTML, CSS, and vanilla JavaScript (plus D3.js via CDN).
- Run a local server for live reload if desired:
```bash
python -m http.server 8000
```
Visit `http://localhost:8000`.
