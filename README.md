## ✨ Features

### 🎨 Visual Design
- **Black background** with **neon green (#00E676)** accent theme
- **Particle network background** (Higgfield canvas effect) with mouse interaction
- **Glassmorphism cards** with hover glow effects
- **Fluid typography** using `clamp()` for responsive text scaling
- Smooth **scroll reveal animations** powered by `IntersectionObserver`

### ⚡ Spark Typing Animation
- **Continuous cursor trail** — tiny sparks follow each typed character
- **Electric color spectrum** on typing: Neon Green, Cyan, Lime, White
- **Ember deletion effect** on backspace: Amber, Orange, Gold
- **Burst spark explosion** at the end of each completed word

### 🕸️ Interactive Tech Stack Graph (D3.js)
- **Force-directed layout** with 70+ skill nodes across 11 categories
- **Color-coded clusters** — each skill domain has a distinct vibrant color
- **Fully draggable** nodes with physics simulation
- **Zoom & pan** for exploring the full graph
- **Cross-cluster links** showing real skill relationships

## 🚀 Getting Started

### Prerequisites
- A modern browser (Chrome, Edge, Firefox)
- No build step, no dependencies, no `npm install`

### Run Locally

```bash
# Clone the repository
git clone https://github.com/harshit311212/the_portfolio.git
cd the_portfolio

# Option 1: Open directly
start index.html        # Windows
open index.html         # macOS

# Option 2: Serve with Python (recommended for full feature support)
python -m http.server 8000
# Visit http://localhost:8000
```
